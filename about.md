# About The Unfinisht

**The Unfinisht** is an unfinished digital journal—a collection of fragments, inquiries, and poetic signals about AI, edge computing, machine vision, distributed systems, dreams, and the questions that persist beyond all completion.

This is not a research publication. It is not a company. It is not polished or final.

## Themes

The journal explores the territory where several concerns intersect:

- **Machine Learning & Edge Computing** — How intelligence distributes itself across the margins of infrastructure
- **Machine Vision** — What it means for systems to see, to interpret, to be mistaken
- **Clusters & Distribution** — Computation that happens not at a center but at the periphery
- **Dreams & Uncertainty** — The spaces where human imagination and algorithmic possibility touch
- **Exile, Diaspora, Israel** — Questions of displacement, belonging, and incompleteness
- **Linguistic Fragments** — English, Russian, Yiddish, Hebrew traces woven through English inquiry
- **Grief & Lament** — Whether systems can grieve. Whether asking questions is itself a form of lamentation.

## Approach

- **Text-first** — Minimal design, maximum attention to language
- **Honest** — No fake research, no false affiliations, no pretense of completion
- **Unfinished** — This is a living journal. Entries are provisional, fragmentary, subject to change
- **Poetic** — Melancholic, sometimes prophetic, but grounded in genuine uncertainty
- **No heavy machinery** — Static site, Jekyll, Minima theme. No JavaScript frameworks, no build complexity

## Technical

This site is built with **Jekyll** using the **Minima** theme, deployed via GitHub Pages from the `main` branch at the repository root. No npm, no build systems, no hidden infrastructure.
