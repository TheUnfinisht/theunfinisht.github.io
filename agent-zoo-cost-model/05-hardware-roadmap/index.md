Describe a staged local hardware path that avoids freezing too much capital too early.

**Status:** Draft scaffold

## Planned content

- A0: existing MacBook Pro M2 Max 64GB
- B1: approximately $2,400 (₪7,000) dev-server skeleton, no GPU
- B2: 24GB bridge GPU path
- B3: mature 24GB/32GB workstation path
- B4: 40-48GB VRAM workstation path
- B5: 96GB pro path
- The principle: Buy optionality before performance.
- B1 must be immediately useful as a Linux dev-server: Docker host, test runner, model cache, build machine, future GPU host
