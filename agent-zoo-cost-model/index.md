## When does local AI hardware beat Web/API coding agents for a 10-senior-engineer team?

This is a field report on OpenCode, Cline, Aider, Devstral, local RTX hardware, Web/API agents, and the strange economics of usable VRAM.

> Hardware does not pay back when it is cheaper. It pays back when it is used enough to reduce recurring LLM spend.

> The question is not: Can local GPUs beat subscriptions? The question is: At what utilization rate does ownership beat access?
